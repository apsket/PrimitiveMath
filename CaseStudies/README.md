# Case Studies (Applied Logical Reasoning)

This section translates formal reasoning tools—logical implication, conditional probability, and structural inference—into real-world decision contexts.

The goal is not narrative explanation, but diagnosis of reasoning structure:

- Where assumptions enter implicitly
- How conditionals are misread or inverted
- How aggregation distorts inference
- Where probabilistic intuition fails under low base rates or regime shifts

Each case study is framed as:

Setup → Formal structure → Reasoning failure → Correct interpretation → System-level implication

Domains include:

- AI / machine learning systems (hallucinations, evaluation, retrieval failure modes)
- Finance (risk modeling, correlation breakdown, regime dependence)
- Statistics (base rate neglect, Simpson’s paradox)
- Sequential decision systems (sports analytics, reinforcement learning analogies)

The intent is to build a transferable reasoning toolkit for quantitative decision-making.
